Hero

Accessibility & motion

  • WCAG 2.2 AA: text ≥ 4.5:1; controls and focus ≥ 3:1.
  • Color always paired with text or icon.
  • 44 px minimum interactive targets and visible focus.
  • Short functional transitions only; no looping motion.
  • Reduced motion disables non-essential transitions.

Information architecture

/ Index→/collection/

Public search and filters stay in the collection URL. Private state never does.

Design guardrails

  • Do keep the English name primary and local name adjacent.
  • Do separate Research from collection progress.
  • Do use original abstract sleep imagery.
  • Don’t imply complete catalogue coverage.
  • Don’t copy official Pokémon artwork or UI styling.
