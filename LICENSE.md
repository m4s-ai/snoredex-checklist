# Licensing scope

This repository is a **mixed work**, mirroring the licensing structure of its upstream data source
`m4s-ai/snoredex-data` (approved by the owner for that repo on 2026-07-26). No single licence
covers all of it, and presenting one as if it did would claim rights the project does not hold.

This project is **noncommercial and source-available**. It is deliberately **not** OSI open source.

> The placement of the following grants is under the owner's direction, consistent with the
> upstream licence decision. The two verbatim licence texts next to this file are the operative
> terms; this document only says which material each covers.

## 1. Original software — PolyForm Noncommercial 1.0.0

Covers the code written for this **view site**: contract validation and sync tooling, state and
reconciliation logic, rendering, tests, and workflow/configuration authored here. The legacy
upstream `analysis_checklist.json` is not a supported production contract.

<https://polyformproject.org/licenses/noncommercial/1.0.0/>

redistribution. Commercial use requires a separate grant from the licensor.
