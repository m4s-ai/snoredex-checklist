# CLAUDE.md — pointer for Claude Code

The working instructions for this repository live in **[`AGENTS.md`](AGENTS.md)**. Read that file —
it is the canonical copy, and this pointer exists so that a Claude-Code session landing here reads
the same operating rules rather than a second, drifting copy.

The two paragraphs worth carrying in before you read anything:

- **This repo is a view, not the source of truth.** Catalogue facts come from
  `m4s-ai/snoredex-data`'s published `analysis_checklist.json`; never re-derive or hand-edit them
  here. The owner's have/don't-have status is private and local.
- **Never render a card as "does not exist".** The upstream checklist promises nobody hunts a card
  that was never made; keep confirmed vs contradicted/disputed distinct.

Anything deeper — the data-contract mapping, the traps, the git/publication rules, and the open
planning questions from [#229] and [#120] — is in [`AGENTS.md`](AGENTS.md).
